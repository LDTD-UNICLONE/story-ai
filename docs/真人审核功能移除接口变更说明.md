# 真人审核功能移除接口变更说明

版本：1.0  
更新时间：2026-08-27  
适用范围：对话型、项目型、Agent、管理端模型能力接口

## 1. 变更结论

平台已移除 APIMart Seedance 真人素材前置审核功能。视频任务不再调用真人素材接口，不再把普通图片转换为 `asset://` 素材，也不再进入真人审核轮询、重试和恢复阶段。

本次没有删除面向前端的视频生成 URL。原有对话视频、项目分镜视频和 Agent 分镜视频接口保持不变，变更内容主要是删除请求字段、响应字段和中间任务状态。

APIMart Seedance 的正常视频生成和 `nsfw_check` 内容检测仍然保留。参考图会作为当前视频模型支持的普通参考媒体直接提交。

## 2. 已删除的公共契约

前端必须停止读取或提交以下字段：

| 业务位置 | 已删除字段或状态 |
| --- | --- |
| 对话视频 `extra` | `private_avatar`、`private_avatar_image_urls` |
| 项目人物创建、编辑、详情、列表和选项 | `requires_private_avatar_review` |
| 项目分镜视频 `extra` | `private_avatar`、`private_avatar_image_urls` |
| Agent 核心资产创建、编辑、详情、列表和准备度 | `requires_private_avatar_review` |
| Agent 主资产参考图请求 | `requires_private_avatar_review` |
| Agent 资产变体参考图请求和绑定清单 | `requires_private_avatar_review` |
| 模型能力 | `configuration.request.capabilities.private_avatar` |
| 任务详情 `extra` | `provider_stage=private_avatar_review`、`private_avatar`、`private_avatar_resume_required` |

这些字段不再产生任何业务效果。旧客户端即使在自由结构的 `extra` 中继续提交，也不会触发真人审核或转换参考图；新客户端不得继续提交。

## 3. 对话型视频接口

### 3.1 提交消息

```http
POST /api/v1/conversations/{conversation_id}/messages
Authorization: Bearer <access_token>
Content-Type: application/json
```

参考图生成视频示例：

```json
{
  "content": "保持人物外观一致，人物缓慢走向镜头",
  "ai_model_id": "视频模型 UUID",
  "client_message_id": "video-turn-001",
  "extra": {
    "generation_mode": "reference",
    "uploaded_images": [
      "https://oss.example.com/character.png",
      "https://oss.example.com/scene.png"
    ],
    "resolution": "720p",
    "duration": 6
  }
}
```

首尾帧示例：

```json
{
  "content": "镜头从人物站立平滑过渡到人物回头",
  "ai_model_id": "视频模型 UUID",
  "extra": {
    "generation_mode": "first_last_frame",
    "first_frame_url": "https://oss.example.com/first.png",
    "last_frame_url": "https://oss.example.com/last.png",
    "resolution": "720p",
    "duration": 6
  }
}
```

接口继续返回 `user_message`、`assistant_message`、`points_cost`、`task_record_id` 和 `task_status`。真人审核字段不会出现在消息或任务响应中。

## 4. 项目型接口

### 4.1 人物资产

人物资产 CRUD 路径保持不变：

```http
GET    /api/v1/projects/{project_id}/characters
POST   /api/v1/projects/{project_id}/characters
GET    /api/v1/projects/{project_id}/characters/{character_id}
PATCH  /api/v1/projects/{project_id}/characters/{character_id}
DELETE /api/v1/projects/{project_id}/characters/{character_id}
```

创建人物示例：

```json
{
  "name": "沈砚",
  "aliases": ["阿砚"],
  "identity": "主角",
  "appearance": "黑发，灰色长风衣",
  "description": "人物描述",
  "prompt": "人物参考图提示词",
  "reference_image": "https://oss.example.com/character.png",
  "extra": {}
}
```

人物列表、详情和资产选项响应不再包含 `requires_private_avatar_review`。

### 4.2 分镜视频生成

```http
POST /api/v1/projects/{project_id}/chapters/{chapter_id}/storyboards/{storyboard_id}/video-generation
Authorization: Bearer <access_token>
Content-Type: application/json
```

```json
{
  "ai_model_id": "视频模型 UUID",
  "generation_mode": "reference",
  "resolution": "720p",
  "return_last_frame": true,
  "prompt": "人物推门进入房间",
  "character_ids": ["人物 UUID"],
  "scene_ids": ["场景 UUID"],
  "prop_ids": [],
  "uploaded_images": [],
  "extra": {
    "duration": 6
  }
}
```

后端收集本次选择的资产参考图，执行模型媒体数量、模式、分辨率和时长校验，然后直接创建视频厂商任务。

## 5. Agent 接口

### 5.1 核心资产

创建核心资产：

```http
POST /api/v1/agent-productions/{production_id}/core-assets
```

```json
{
  "asset_type": "character",
  "canonical_name": "沈砚",
  "aliases": ["阿砚"],
  "content": {
    "appearance": "黑发，灰色长风衣"
  }
}
```

上传或清空主资产参考图：

```http
PUT /api/v1/agent-productions/{production_id}/core-assets/{asset_type}/{asset_id}/reference-image
```

```json
{
  "expected_lock_version": 0,
  "reference_image": "https://oss.example.com/character.png"
}
```

`reference_image=null` 表示清空参考图。资产变体参考图接口使用相同请求结构：

```http
PUT /api/v1/agent-productions/{production_id}/core-assets/{asset_type}/{asset_id}/variants/{variant_id}/reference-image
```

核心资产列表、详情、准备度和参考图更新响应不再包含 `requires_private_avatar_review`。

### 5.2 分镜组视频生成

```http
POST /api/v1/agent-productions/{production_id}/episodes/{chapter_id}/storyboards/{storyboard_id}/video-generations
```

```json
{
  "expected_core_asset_lock_version": 1,
  "expected_episode_revision": 3,
  "expected_storyboard_revision": 2,
  "expected_video_config_version": 1,
  "duration_seconds": 8,
  "idempotency_key": "storyboard-video-v1",
  "video_model_id": "视频模型 UUID",
  "video_resolution": "1080p",
  "prompt": "加强人物停顿后的眼神变化"
}
```

Agent 仍按分镜组绑定的人物、场景和道具选择参考图，并按 `@图片1`、`@图片2` 顺序提交模型。绑定清单不再包含真人审核标记。

## 6. 模型能力接口

管理端和用户端模型选项中的以下能力保持有效：

- `modes`
- `request_keys`
- `media_limits`
- `ratios`
- `resolutions`
- `duration`
- `supports_async_task`
- `task_endpoint`

`configuration.request.capabilities.private_avatar` 已删除。前端动态表单不得再根据该字段渲染真人审核开关。

Seedance 视频请求中的 `nsfw_check` 是视频生成内容检测参数，不是已删除的真人素材前置审核。当前适配器默认值为 `true`；如果模型能力的 `request_keys` 暴露该字段，客户端提交的布尔值会按现有模型参数规则处理。

## 7. 任务状态与进度

删除真人审核后，异步视频任务流程为：

```text
创建平台任务
  → 提交视频厂商任务
  → 保存 provider_task_id
  → 查询厂商视频进度
  → 保存视频结果
  → 最终积分结算
```

任务仍通过现有状态接口和 SSE 获取进度。`progress_percent` 只表示当前视频厂商任务进度，不再表示真人素材审核进度。

任务 `extra.provider_stage` 在视频厂商任务已创建后可为 `video_generation`，不会再返回 `private_avatar_review`。

## 8. 前端适配清单

1. 删除所有“真人审核”“真人素材审核”开关和提示文案。
2. 删除 `private_avatar`、`private_avatar_image_urls` 请求参数。
3. 删除 `requires_private_avatar_review` 的表单字段、类型声明、列表列和响应读取逻辑。
4. 删除对 `provider_stage=private_avatar_review` 的页面状态和进度分支。
5. 删除对 `extra.private_avatar` 和 `private_avatar_resume_required` 的读取。
6. 模型动态参数继续以 `configuration.request.capabilities.request_keys` 为准。
7. 视频生成仍按 `task_record_id` 查询或订阅任务进度，不需要增加新的轮询接口。

## 9. 数据库迁移

部署新版本后执行：

```bash
uv run --frozen alembic upgrade head
uv run --frozen alembic check
```

迁移 `0061_remove_private_avatar_review` 会删除：

- `apimart_private_avatar_assets` 表；
- `project_characters.requires_private_avatar_review` 字段。

该操作会永久删除历史真人审核记录。生产环境执行前应先完成数据库备份。
