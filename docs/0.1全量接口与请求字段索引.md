# 0.1 全量接口与请求字段索引

代码核对日期：2026-09-30。由当前注册路由、依赖及 Pydantic/OpenAPI 声明逐项提取；覆盖全部 226 个方法/路径组合，包括仍注册的 Agent 兼容接口。正文流程和响应对象见各类主文档。

本索引用于核对路径、鉴权、查询参数与请求字段，不将数据库模型或未注册的服务函数视为公开接口。默认前缀 `/api/v1`，下表省略；路径参数通常为 UUID，通用 task-records/{task_record_id} 和供应商 tasks/{task_id} 接收字符串后另行校验。

声明字段可空不等于业务允许清空；自定义验证器、模式条件、版本冲突、归属、模型能力、计费及响应脱敏规则以业务文档和所链源代码为准。未声明的额外字段是否拒绝由各 Schema 的 extra 策略决定，不得统一假定为 forbid。涉及配置的数值列出代码默认值，部署可调整。微信回调直接读取原始请求，不因 OpenAPI 缺少 requestBody 就视为无正文。

阅读入口：[通用](0.0通用接口文档.md) · [对话](1.0对话型接口文档.md) · [项目](2.0项目型接口文档.md) · [Agent](3.0Agent接口文档.md) · [作品](4.0作品展示接口文档.md) · [管理端](5.0管理端整体接口文档.md)。
