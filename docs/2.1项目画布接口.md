# 2.1 项目画布接口

代码核对日期：2026-09-30。本文定义当前画布相关请求与响应，接口分类总表、鉴权、统一响应外层、项目 CRUD 见[项目型接口文档](2.0项目型接口文档.md)。前端调用流程见[接入指南](2.2项目画布前端接入指南.md)。

全站请求字段声明见[接口索引](0.1全量接口与请求字段索引.md)；通用上传审核、任务与积分的完整入口见[通用接口](0.0通用接口文档.md)。

## 1. 路径与分页

为减少重复，下文使用以下路径缩写，实际调用必须展开：

| 缩写 | 完整默认路径 |
| --- | --- |
| P | `/api/v1/projects/{project_id}` |
| C | `/api/v1/projects/{project_id}/canvases/{canvas_id}` |
| N | `/api/v1/projects/{project_id}/canvases/{canvas_id}/nodes/{node_id}` |

所有响应结构均指统一响应内的 `data`。所有分页接口接受 page（默认 1，最小 1）、page_size（默认 20，1–100），返回 items/total/page/page_size。画布、媒体、生成历史、画布任务按 created_at、id 倒序；迁移记录按 created_at、id 升序。

## 2. 画布管理

| 方法与路径 | 请求 | 响应 data |
| --- | --- | --- |
| POST `P/canvases` | JSON name 必填 | CanvasOut，revision=1，nodes/edges 为空 |
| GET `P/canvases` | 分页查询参数 | CanvasSummary 分页 |
| GET `C` | 无请求体 | CanvasOut |
| PATCH `C` | CanvasPatch，见第 3 节 | 更新后的完整 CanvasOut |
| PATCH `C/layout` | CanvasLayoutPatch，见第 3 节 | id/revision/viewport/nodes（本次修改的几何信息） |
| DELETE `C` | 必填查询参数 expected_revision，integer≥1 | id/deleted |

创建 name 为 1–128 字符，去首尾空白后不能为空；创建时不接受 viewport/nodes 等其他字段。新画布 viewport 默认 `{x:0,y:0,zoom:1}`。

创建请求（CanvasCreate）：

```json
{"name":"主画布"}
```

### 2.1 画布响应对象

| CanvasSummary 字段 | 类型 |
| --- | --- |
| id / project_id | UUID string |
| name | string |
| revision | integer，≥1 |
| viewport | `{x:number,y:number,zoom:number}` |
| created_at / updated_at | datetime string |

CanvasOut 在摘要基础上增加 nodes（CanvasNodeOut[]）与 edges（CanvasEdgeOut[]）。nodes 按 UUID 字符串排序；edges 按 target_id、input、position、id 排序，不代表绘制层级或执行顺序。

### 2.2 删除画布

示例：`DELETE C?expected_revision=12`，无 JSON 请求体。响应 data 示例：

```json
{"id":"00000000-0000-0000-0000-000000000801","deleted":true}
```

版本不符返回 409/code 40978，data.current_revision 是当前版本。成功后删除该画布及节点、连线，允许删除最后一张画布；不会自动新建替代画布。不存在/重复删除返回 404/code 40470。

删除不取消生成任务、不退款，也不清理项目媒体及生成历史。历史与批量生成结果仍可按原 ID 读取；画布任务列表要求画布存在，删除后不能再查询。项目级删除行为另见总文档。

## 3. 节点、分组与连线编辑

### 3.1 原子保存 CanvasPatch

`PATCH C` 的 JSON 字段：

| 字段 | 必填/默认 | 规则 |
| --- | --- | --- |
| expected_revision | 必填 | 严格整数≥1，不接受字符串或布尔值 |
| name | 省略不改 | 与创建名称规则一致，不接受 null |
| viewport | 省略不改 | 完整替换视口；不能为 null；内部省略字段恢复默认值 |
| upsert_nodes | [] | CanvasNodeInput[]；新增或完整替换已有节点的可写字段 |
| update_nodes | [] | CanvasNodePatch[]；只局部编辑已存在节点 |
| delete_node_ids | [] | UUID[]；删除节点，自动移除相邻连线 |
| upsert_edges | [] | CanvasEdgeInput[]；新增或替换连线，有固定引用保留规则，见第 4 节 |
| delete_edge_ids | [] | UUID[]；删除连线 |

至少提供一种修改。五个操作数组合计最多 500 项；每个数组内部 ID 不重复；同一节点不能同时出现在新增/局部编辑/删除数组，同一连线不能同时修改和删除。Schema 序列化后的修改内容不得超过 2MB。

整个请求校验并在一个事务中保存；任一项失败不部分应用。成功画布 revision 加 1。删除不存在的节点/连线 ID 当前是无操作，但请求成功仍增加 revision；局部编辑不存在的节点则返回 404。

### 3.2 完整节点 CanvasNodeInput

| 字段 | 类型 | 必填/默认与限制 |
| --- | --- | --- |
| id | UUID | 必填，由客户端生成 |
| kind | enum | 必填：text/image/video/group；已有节点不能更改 kind |
| title | string | 默认空字符串，最长 128 |
| x / y | number | 默认 0，各在 -1000000 至 1000000 |
| width / height | number | 默认 320/240，各在 1–10000 |
| parent_id | UUID 或 null | 默认 null；必须指向同画布 group 节点 |
| media_id | UUID 或 null | 默认 null；仅 image/video 节点可绑定同项目、类型匹配的素材 |
| content | CanvasContent | 默认 `{text:"",generation:null}` |

CanvasContent 仅接受 text（默认空字符串，最长 10000）和 generation（默认 null，结构见第 6 节）。空提示词可保存草稿，但提交生成时不能空白。数值不能是 NaN/Infinity。

CanvasNodeOut 在上述字段上增加以下只读字段：

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| content_revision | integer | 新节点为 1 |
| import_record_id | UUID 或 null | 旧数据迁移来源 |
| latest_generation_id | UUID 或 null | 最近提交的生成记录；手动选择历史结果时清空 |
| selected_generation_id | UUID 或 null | 当前选中的成功结果 |

只读字段不能放入 upsert_nodes/update_nodes。upsert_nodes 省略的可写字段按默认值覆盖已有值，因此编辑现有节点优先使用 update_nodes。

创建文本节点和图像节点示例（CanvasPatch）：

```json
{
  "expected_revision":1,
  "upsert_nodes":[
    {"id":"00000000-0000-0000-0000-000000000101","kind":"text","content":{"text":"雨夜街道，暖色灯光"}},
    {"id":"00000000-0000-0000-0000-000000000102","kind":"image","x":400}
  ]
}
```

### 3.3 局部编辑 CanvasNodePatch

update_nodes 每项必填 id，并至少修改 title/parent_id/media_id/content 中一项：

- 省略的字段保持原值。title 不接受 null，可用空字符串清空。
- parent_id、media_id 可用 null 解除绑定。修改媒体会清空 selected_generation_id。
- content 只局部合并 text 与 generation 两个直接子字段；text 不接受 null，可用空字符串清空。
- content.generation=null 清除生成配置；传对象则替换整份生成配置，必须带 ai_model_id，省略 parameters 恢复为空对象。
- content=null 或 content={} 均无效。kind、几何字段、只读指针不能放在 update_nodes 中。

示例（CanvasPatch）：

```json
{
  "expected_revision":2,
  "update_nodes":[
    {"id":"00000000-0000-0000-0000-000000000102","title":"街景","content":{"text":"电影质感"}}
  ]
}
```

### 3.4 布局专用保存

`PATCH C/layout` 接受 expected_revision（必填严格整数≥1）、nodes（默认 []，最多 500 项）和 viewport（省略不改，不能为 null）。至少修改一个节点或视口。

nodes 每项必填 id，另提供 x/y/width/height 中至少一项；省略保持原值，null 无效，范围与完整节点相同。只允许已有同画布节点，ID 不重复。不支持 title/content/parent_id/media_id/kind。

示例（CanvasLayoutPatch）：

```json
{
  "expected_revision":3,
  "nodes":[{"id":"00000000-0000-0000-0000-000000000102","x":480,"y":120}],
  "viewport":{"x":0,"y":0,"zoom":0.8}
}
```

viewport.x/y 范围为 ±1000000，zoom 范围为 0.05–8，默认分别 0/0/1。视口对象按整体替换。响应 nodes 仅包含本次修改的节点，按请求顺序返回每项 id/x/y/width/height；不是完整节点列表。布局保存只增加画布 revision，不增加 content_revision、不重置生成指针。

### 3.5 删除与图结构限制

删除节点/连线示例（CanvasPatch）：

```json
{
  "expected_revision":4,
  "delete_node_ids":["00000000-0000-0000-0000-000000000102"],
  "delete_edge_ids":[]
}
```

- 最终画布最多 1000 个节点、3000 条连线。
- 分组关系与连线关系分别禁止成环；连线两端必须是同画布存在的非 group 节点，不能自连。
- 删除分组只解除直接子节点的 parent_id，不自动删除子节点。删除子树须显式传入全部待删后代，仍受 500 操作上限约束。
- 节点的 content、media_id 或入边集合（含固定媒体/文本快照）变化，会增加该节点 content_revision；标题、位置、尺寸、分组变化不会。
- 删除节点/连线不会同步改写其他节点提示词里的 `@{连接ID}`。遗留无效引用会在提交生成时被拒绝。

## 4. 连线与引用

### 4.1 CanvasEdgeInput / CanvasEdgeOut

| 字段 | 类型 | 默认/限制 |
| --- | --- | --- |
| id / source_id / target_id | UUID | 全部必填 |
| input | enum | 默认 reference；可取 reference/first_frame/last_frame/text |
| position | integer | 默认 0，严格整数 0–2999 |
| media_id | UUID 或 null | 默认 null；只允许固定图片，绑定规则见下 |
| text_source | input/result 或 null | 默认 null；input=text 时必填且 media_id 必须为 null |
| refresh_text | boolean | 默认 false，严格布尔值；仅文本连线支持 true；只作为请求指令，不出现在响应 |

CanvasEdgeOut 额外返回只读 text_snapshot（null 或 `{text:string,generation_id:UUID|null}`），客户端不能写入。文本最长 10000 字符。

同一目标下 input+position 不能重复；同一 source_id+target_id+input 不能重复。因此同一文本源到同一目标当前只能有一条 text 连线，不能同时建 input/result 两条。

| input | 保存规则 | 生成时规则 |
| --- | --- | --- |
| reference | 通用非分组节点连线 | 当前仅图片源可作媒体输入；文本引用须用 text，视频源不支持 |
| first_frame / last_frame | 只能 image→video，position 必须为 0 | 必须有首帧；是否允许仅首帧由具体视频模型校验 |
| text | 源必须为 text，目标为任意非 group 节点 | 必须通过提示词标签使用；不自动执行源节点 |

保存合法不等于所选模型可生成：例如 text→image 的 reference 连线可作为图结构保存，但生成拒绝该输入，必须改为 text 连线；文本生成目前也不支持图片输入。

### 4.2 图片固定版本

图片连线创建时省略 media_id 或传 null，固定源节点当前 media_id；源节点尚无图片时允许空连线保存，但提交生成失败。

修改同 ID、同图片源的连线时，省略 media_id 保留原固定图片；显式 media_id=null 重新读取源节点当前图片；也可显式指定源节点当前 media_id 或该连线原固定 media_id，不能指定任意项目图片。

源节点后来换图，不自动改变已固定的连线。候选中的 source_changed 仅表示源和固定版本不同，不代表旧版本不可用。

### 4.3 文本固定快照

- text_source=input：读取源节点 content.text；可保存空文本快照，但空白文本不可用于生成引用。
- text_source=result：读取源节点 selected_generation_id 对应的成功文本结果，要求记录属于当前用户/项目/画布/源节点。不会回退到输入文本，也不会自动生成上游；无可用结果或文本超长时保存失败。
- 新连线、更换 source_id/text_source、显式 refresh_text=true 时重新取快照。同一源和模式且不刷新则保留原快照。
- 源文本或已选结果变化只令 source_changed=true，固定快照仍可使用。要更新下游内容，前端明确发送刷新操作。

示例：保存文本引用及目标提示词（CanvasPatch，假定两个节点已存在）：

```json
{
  "expected_revision":2,
  "upsert_edges":[
    {
      "id":"00000000-0000-0000-0000-000000000201",
      "source_id":"00000000-0000-0000-0000-000000000101",
      "target_id":"00000000-0000-0000-0000-000000000102",
      "input":"text",
      "text_source":"input",
      "position":0
    }
  ],
  "update_nodes":[
    {"id":"00000000-0000-0000-0000-000000000102","content":{"text":"绘制场景：@{00000000-0000-0000-0000-000000000201}"}}
  ]
}
```

刷新时在同一连线的完整可写字段中添加 refresh_text=true；upsert_edges 不是局部更新接口，必须继续携带 id/source_id/target_id/input/text_source 等字段。

### 4.4 候选接口

`GET N/reference-inputs` 无查询参数，返回 `{revision,content_revision,items}`。只查询目标节点已有入边，不列出全项目素材、历史消息或所有节点。items 先返回图片候选，再返回文本候选。

| 候选字段 | 图片 | 文本 |
| --- | --- | --- |
| kind | image | text |
| reference_id / source_node_id | 连线 ID / 源节点 ID | 同左 |
| label | 图片1、图片2… | 文本1、文本2… |
| input / position | 连线类型及位置 | text 及位置 |
| available | 固定媒体存在且 source_verified=true | 固定快照存在且文本非空白 |
| source_changed | 固定 media_id 与源节点当前 media_id 不同 | 当前来源快照与固定快照不同 |
| media_id / media | UUID 或 null / ProjectMediaOut 或 null | 不返回 |
| text_source / text_snapshot | 不返回 | input/result；固定快照或 null |

图片按 reference、first_frame、last_frame，再按 position、id 排序编号；文本按 position、id 排序编号。available 不包含 Seedance 审核是否通过的判断；图片审核看 media.review.can_reference。

`GET N/image-inputs` 返回同样的外层及图片字段，但不包含 kind，也没有文本项。它不是 reference-inputs 的完全同型响应。

### 4.5 提示词中的引用规则

content.text 持久化标签必须为 `@{连接UUID}`，不能传 node_id/media_id/generation_id，也不能保存 `@图片1` 或 `@文本1` 显示编号作为引用。

- 生成时只解析目标节点入边。找不到对应连线、标签格式错误或引用空白文本会返回 400/code 40073。
- 文本快照只在标签出现处展开；同一文本可多次展开，snapshot.inputs 只记录一次。未引用的文本连线不自动追加到提示词，也不阻止生成。
- 展开只执行一层，插入文本中的标签按普通文字处理，不递归追踪上游。
- 图片入边即使没有出现在提示词中也会作为模型输入；所有图片入边都要满足来源和审核条件。reference 图片按 URL 去重，标签映射到实际提交的图片编号；首尾帧标签映射为对应说明。
- 提示词先去首尾空白，必须非空；引用展开后不超过 10000 字符，超长直接拒绝，不截断。

## 5. 项目素材与 Seedance 图片审核

### 5.1 素材接口

| 方法与路径 | 请求 | 响应 data |
| --- | --- | --- |
| POST `P/media/images` | multipart/form-data，必填 file | ProjectMediaOut |
| POST `P/media/imports` | ProjectMediaImport | ProjectMediaOut |
| GET `P/media` | 分页 | ProjectMediaOut 分页 |
| GET `P/media/{media_id}` | 无请求体 | ProjectMediaOut |
| POST `P/media/batch` | JSON ids，1–100 个 UUID | items/total/missing_ids |
| POST `P/media/{media_id}/review` | 无请求体 | SeedanceImageOut，不是 ProjectMediaOut |

项目上传仅接受识别为图片的文件，非空且不超过 max_upload_size_mb 配置，并经过公共上传校验。同项目相同内容 SHA256 复用媒体记录；有当前用户、当前审核配置下的同内容审核记录时可复用其文件。**项目上传不会自动提交审核。**

导入请求（ProjectMediaImport）：

```json
{"source_type":"seedance_image","source_id":"00000000-0000-0000-0000-000000000301"}
```

source_type 目前只有 seedance_image；source_id 为本人 SeedanceImage 的 image_id，不是 media_id。导入本身不要求已审核成功，也不发起新审核；后续能否生成按当前状态和所选模型判断。

批量请求（ProjectMediaBatchRequest）：

```json
{"ids":["00000000-0000-0000-0000-000000000401"]}
```

批量去重并按请求顺序返回已找到记录；total 为本次找到数量，缺失和跨项目 ID 均进入 missing_ids。读取媒体接口只附带已有审核信息，不触发登记或重审。

### 5.2 ProjectMediaOut

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| id / project_id | UUID | 项目素材及所属项目 |
| media_type | image/video | 文件类型 |
| source_type | string | 来源标记，如 upload、seedance_image、canvas_generation；历史迁移也可能有其他值 |
| source_verified | boolean | 来源凭证是否可用于审核与生成，不等于审核通过 |
| source_id | UUID 或 null | 对应来源记录 |
| url / filename | string | 文件地址与名称 |
| created_at | datetime | 登记时间 |
| review | SeedanceImageOut 或 null | 当前用户、当前审核配置匹配到的审核信息 |

当前没有任意 URL 登记、项目视频文件上传、媒体编辑或删除接口；画布生成的图像/视频会自动登记媒体。上传/导入不会自动创建节点或连线。历史 source_verified=false 媒体可预览，但不能审核或用于生成，需要重新上传原文件并更新绑定。

### 5.3 审核登记与复用

`POST P/media/{media_id}/review` 要求来源已验证且类型为 image。已匹配到审核记录时原样复用状态，包括 failed/uncertain，不会自动重试；未匹配则读取可信已登记图片、计算内容指纹并调用共享审核登记流程。共享审核图片必须小于 30MB 且不超过平台上传上限。

审核记录按用户、供应商配置范围与图片内容复用；同一审核配置下切换 Seedance 型号，不需重新上传/审核。配置范围变化时不能假定旧记录继续可用。后端没有自动判断“非真人”并跳过门禁的逻辑。

当前门禁适用于 vendor=apimart、model_type=video，且 model_id（去首尾空白并转小写）属于：seedance-2.0、seedance-2.0-fast、seedance-2.0-mini、seedance-2-0、seedance-2.0-face、seedance-2.0-fast-face、seedance-2.5。这是代码白名单，不代表所有含 Seedance 名称的模型都使用相同门禁。

使用这些模型时，参考图和首尾帧都要求审核 ready 且具有有效内部资产；纯文生视频无图片时无图片审核输入。生成接口不替前端自动发起审核。

### 5.4 SeedanceImageOut 与重试

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| url/object_key/filename/content_type/file_type | string | 共享上传文件信息 |
| size | integer | 字节数 |
| media_info | object 或 null | 公共媒体信息 |
| image_id | UUID | 后续查询/重试使用的图片审核 ID |
| review_status | enum | pending/processing/ready/failed/uncertain |
| can_reference | boolean | ready 且与当前供应商配置兼容 |
| can_retry | boolean | failed/uncertain 且配置兼容 |
| retry_requires_confirmation | boolean | uncertain 且无供应商任务 ID、配置兼容时为 true |
| review_error | string 或 null | 已脱敏原因 |
| reused | boolean | 本次是否复用记录；不代表审核成功 |

pending/processing 表示等待或处理中，ready 表示已就绪，failed 为失败，uncertain 为提交/审核结果不明确。内部 submitting 对外显示 processing。前端以 can_reference/can_retry 判断操作权限。

轮询 `GET /api/v1/uploads/images/{image_id}`；重试调用 `POST /api/v1/uploads/images/{image_id}/retry-review`，可省略请求体或传 `{}`。需要确认时，在用户确认后提交 SeedanceImageRetryRequest：

```json
{"confirm_resubmit":true}
```

uncertain 且已知供应商任务 ID 时恢复查询；未知任务 ID 时未确认重提返回 409/code 40999。pending/processing/ready 调用重试不会重新开始审核。重试返回新的状态对象，不保证立即 ready。

## 6. 模型配置与生成

### 6.1 节点生成配置

content.generation 为 null 或 CanvasGenerationSettings。后者必填 ai_model_id（UUID），parameters 默认空对象。不接受额外 system_prompt、prompt、image_urls 或手动 video_mode 字段；提示词放 content.text，媒体由连线编译。

示例：局部设置图像模型（CanvasPatch，示例模型 UUID 需替换为实际选项）：

```json
{
  "expected_revision":3,
  "update_nodes":[
    {
      "id":"00000000-0000-0000-0000-000000000102",
      "content":{"generation":{"ai_model_id":"00000000-0000-0000-0000-000000000501","parameters":{"n":1}}}
    }
  ]
}
```

参数字段可省略或为 null（提交模型前忽略 null）；非 null 字段必须属于节点类型白名单：

| 节点类型 | 参数 | Schema 限制 |
| --- | --- | --- |
| text | temperature / max_tokens | 数值 0–2 / 严格整数 1–65536 |
| image | aspect_ratio / resolution / size | 各为 1–32 字符字符串 |
| image | n / seed | 严格整数 1–10 / -1–2147483647 |
| video | aspect_ratio / resolution | 各为 1–32 字符字符串 |
| video | duration / seed | 严格整数 1–120 / -1–2147483647 |
| video | generate_audio / watermark | 严格布尔值 |

这些是画布层允许范围，不代表每个模型支持全部取值；还须满足模型启用状态、维护状态、供应商能力与参数组合校验。模型 model_type 必须与节点 kind 相同；group 不可生成。

画布完成连线、引用和参数白名单校验后，文本/图像/视频请求进入与对话相同的供应商校验入口，在扣费和创建任务前拒绝不支持的参数组合。画布的输入协议保持本节定义；不支持的供应商统一返回 HTTP 400/code 40005。

### 6.2 视频模式由连线确定

| 输入 | generation_mode | 内部 video_mode/capability |
| --- | --- | --- |
| 无图片入边（可有文本引用） | text_to_video | text_to_video |
| reference 图片 | reference | image_to_video |
| first_frame，可选 last_frame | first_last_frame | first_last_frame |

reference 不得与首尾帧混用；只有 last_frame 不合法；具体模型可能要求首尾帧成对。图片数量、比例、时长等由供应商校验继续约束。文本引用只展开提示词，不改变视频模式或图片数量。

### 6.3 提交生成

`POST N/generations`，CanvasGenerationSubmit：

```json
{"expected_content_revision":2,"idempotency_key":"00000000-0000-0000-0000-000000000601"}
```

只接受两个必填字段：expected_content_revision 为严格整数≥1，idempotency_key 为 UUID。提交前先保存提示词、配置和连线；接口读取数据库当前节点，不接受临时覆盖模型/提示词/输入。

校验通过后冻结输入/模型配置，按已有计费逻辑检查余额、扣费、创建 pending 任务并登记队列投递；响应不是生成完成。新提交设置 latest_generation_id，增加画布 revision，但不增加节点 content_revision，也不返回新的画布 revision。

扣费、任务、生成历史、节点 latest_generation_id、画布 revision 和待投递记录在同一提交流程中保存；任务额度校验、记录写入或投递登记失败时，本次修改一起回滚。数据库提交成功后才发送到队列；队列暂时不可用时，已提交任务保留 pending 并等待自动补偿投递，不能据此认定生成失败或重新扣费。

同项目/画布/节点下相同幂等键、相同提交内容版本，返回已有生成记录，不创建重复任务；同键不同提交版本返回 409/code 40980。网络重试保留原请求两个字段；用户主动重新生成使用新键。幂等复用仍要求画布存在。

提交和历史项响应 GenerationOut：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id / canvas_id / node_id / task_record_id | UUID | 生成记录、画布、节点、异步任务 |
| status | string | pending/running/success/failed |
| content_revision | integer | 提交时节点版本，不是当前节点版本 |
| points_cost | integer | 任务当前积分值 |
| snapshot | object | 提交快照，见下 |
| result | object | 未有结果时 {}，成功结构见下 |
| failed_reason | string 或 null | 任务失败原因 |
| created_at | datetime string | 生成记录创建时间 |

snapshot 返回 content、model、prompt、inputs、model_extra、kind；不返回内部 seedance_provider_scope。model 含 id/model_id/vendor/model_type/nickname/configuration；prompt 为编译后文本。图片 inputs 项含 reference_id/source_node_id/media_id/input/position/url；被使用的文本项含 reference_id/source_node_id/input/position/text_source/text/generation_id。model_extra 为编译后的运行参数，不可原样当作节点 parameters 回传。

### 6.4 生成结果与自动应用

图像、视频取得厂商任务 ID 后，生成 Worker 立即交给与对话共用的后台回收流程。前端继续使用同一 task_record_id 查询；回收投递、查询或转存暂时失败不会重新调用生成接口或直接退款。已受理任务即使本地状态为 pending，也不会被再次提交。厂商最终结果由后端统一更新生成历史、结算或退款；结果应用仍遵循画布版本与用户选择规则。

成功结果结构：

| result 字段 | 文本结果 | 图片/视频结果 |
| --- | --- | --- |
| text | 输出文本 | null |
| urls | [] | 结果地址数组 |
| media_ids | [] | 对应项目媒体 UUID 数组 |
| auto_applied | boolean | boolean |

只有画布/节点仍存在、项目可访问、latest_generation_id 仍指向此任务、content_revision 与提交时一致且类型相同时，结果才自动选中。自动应用更新 selected_generation_id，并绑定首个结果 media_id（文本为 null），节点内容版本和画布版本各加 1。

文本生成不会把结果覆盖回 content.text。通过 selected_generation_id 读取结果；content.text 仍是输入。生成成功但 auto_applied=false 时结果保留在历史中，不应强制覆盖用户当前编辑。仅凭 result 非空不代替任务 status 判断。

### 6.5 历史、选择、任务与批量结果

| 方法与路径 | 请求 | 响应 |
| --- | --- | --- |
| GET `N/generations` | 分页参数 | GenerationOut 分页，含 snapshot/result |
| POST `N/generations/{generation_id}/select` | CanvasGenerationSelect | selected_generation_id/media_id/content_revision/revision |
| GET `C/tasks` | 分页、node_id 可选、status 默认 active | 任务摘要分页 |
| POST `C/generations/batch` | CanvasGenerationBatchRequest | items/total/missing_ids |

选择请求示例（CanvasGenerationSelect）：

```json
{"expected_content_revision":3,"result_index":0}
```

expected_content_revision 必填严格整数≥1；result_index 默认 0，严格整数 0–99，还须小于实际结果数量；文本只有下标 0。只能选同节点、对应类型、status=success 且有结果的历史记录。选择后绑定媒体/已选结果，清空 latest_generation_id，节点和画布版本各加 1；不会把历史提示词或模型配置恢复到节点，也不会停止已在执行的任务。

任务 status 可选 active/pending/running/success/failed/all，active 表示 pending+running。node_id 仅作过滤，不要求节点仍存在；画布本身必须存在。每项字段为 generation_id/task_record_id/node_id/generation_type/status/phase/content_revision/points_cost/created_at/stop_polling/next_poll_seconds，不含 snapshot、prompt 或结果正文。轮询提示位于每个 item，不在分页外层；活动任务 next_poll_seconds=1，终态 next_poll_seconds=null。phase 为 queued/generating/persisting/completed/failed；persisting 表示厂商完成后正在保存成品，status 仍为 running。可通过通用 `/task-records/stream?ids=<task_record_id>` 合并订阅通知，契约见 0.0 通用文档。

批量请求（CanvasGenerationBatchRequest）：

```json
{"ids":["00000000-0000-0000-0000-000000000701"]}
```

ids 为 1–100 个 generation_id。按请求去重后的顺序返回；缺失、跨项目/画布或任务不属于当前用户的记录进入 missing_ids，total 是本次找到数量。每项字段为 id/canvas_id/node_id/task_record_id/generation_type/status/content_revision/points_cost/result/failed_reason/created_at；与 GenerationOut 相比增加 generation_type，省略 snapshot，也没有 stop_polling/next_poll_seconds。

生成历史和结果 batch 不要求节点/画布仍存在，但仍校验可访问的普通项目。未知历史路径组合返回空列表，不用于判断编辑对象是否存在。

## 7. 旧数据迁移记录

`GET P/import-records` 返回分页摘要；`GET P/import-records/{record_id}` 返回详情。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id / project_id / source_id | UUID | 归档、项目、旧资源 ID |
| source_type | string | 旧资源类型 |
| nodes | array | 迁移时的 `{canvas_id,node_id}` 定位，不保证编辑对象现在仍存在 |
| warnings | array | 迁移警告 |
| created_at | datetime | 归档时间 |
| data | object | 仅详情返回，保存原始数据 |

接口只读，没有恢复/删除/重新导入操作。旧内容迁移不会凭空创建 CanvasGeneration；迁移节点生成历史为空不等于旧内容丢失。节点 import_record_id 仅用于查归档。

## 8. 主要异常与处理

| HTTP / code | 场景 | 处理 |
| --- | --- | --- |
| 422 / 42200 | 请求字段、类型、枚举、范围或额外字段不合法 | 根据 data.loc 定位请求字段 |
| 404 / 40407 | 项目不可访问 | 返回项目列表 |
| 404 / 40470 | 画布不存在 | 关闭画布并刷新列表 |
| 404 / 40471 | 项目媒体不存在 | 重新读取素材列表 |
| 404 / 40472 | 节点不存在/不属于画布 | 重新读取画布 |
| 404 / 40473 | 待选择生成记录不存在 | 刷新历史 |
| 404 / 40474 | 迁移记录不存在 | 停止读取该记录 |
| 404 / 40404 | 模型不存在、未启用或类型不符 | 刷新可选模型 |
| 400 / 40005 | 当前供应商或模型类型尚不支持 | 更换支持的模型 |
| 503 / 50301 | 模型维护中 | 更换模型或等待恢复 |
| 400 / 40070 | 图结构、绑定、文本快照不合法 | 修正编辑请求 |
| 400 / 40073 | 提示词、引用、参数类型、结果选择不合法 | 修正生成输入/结果下标 |
| 409 / 40978 | 画布版本冲突 | 读取 data.current_revision，重新拉取、合并后保存 |
| 409 / 40979 | 节点内容版本冲突 | 读取 data.current_content_revision，重新确认输入 |
| 409 / 40980 | 幂等键被用于其他内容版本 | 新生成使用新键；网络重试使用原请求 |
| 400 / 40016 | 图片来源、审核、配置兼容性等不满足 | 按审核状态修复，不无限自动重提 |
| 409 / 40999 | 不明确审核提交要求用户确认 | 确认后传 confirm_resubmit=true |

上传、模型维护、供应商校验、计费、任务上限等还可能返回共享错误；此表不是全站错误码穷举。提交失败不等于已创建任务；拿到生成记录后才用 task_record_id 轮询。
