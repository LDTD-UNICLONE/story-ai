# 视频生成接口更新文档

更新时间：2026-06-30

本次更新对火山方舟 Ark 视频生成的入参做了统一整理，覆盖“文生视频”“参考生成 / 多模态参考”和“首尾帧模式”，其中首尾帧模式同时兼容“只传首帧”和“同时传首帧、尾帧”。

## 1. 对话型视频生成

接口：

```http
POST /api/v1/conversations/{conversation_id}/messages
```

请求体：

```json
{
  "content": "视频提示词",
  "ai_model_id": "可选，视频模型 ID",
  "extra": {
    "generation_mode": "reference",
    "resolution": "720p"
  }
}
```

返回仍沿用原有消息发送结构，视频生成会创建异步任务：

```json
{
  "user_message": {},
  "assistant_message": {},
  "points_cost": 10,
  "task_record_id": "任务 ID",
  "task_status": "pending"
}
```

轮询接口：

```http
GET /api/v1/conversations/{conversation_id}/generation-tasks/{task_record_id}
```

## 3. 参考生成 / 多模态参考

适用场景：需要给模型提供参考图、参考视频、参考音频，让模型结合提示词生成视频。

推荐传法：

```json
{
  "content": "参考这些素材生成一段镜头稳定的视频",
  "extra": {
    "generation_mode": "reference",
    "resolution": "720p",
    "media_items": [
      {
        "type": "image_url",
        "image_url": { "url": "https://example.com/ref-image.png" },
        "role": "reference_image"
      },
      {
        "type": "video_url",
        "video_url": { "url": "https://example.com/ref-video.mp4" },
        "role": "reference_video"
      },
      {
        "type": "audio_url",
        "audio_url": { "url": "https://example.com/ref-audio.mp3" },
        "role": "reference_audio"
      }
    ]
  }
}
```

也兼容扁平字段：

```json
{
  "extra": {
    "generation_mode": "reference",
    "images": ["https://example.com/ref-image.png"],
    "videos": ["https://example.com/ref-video.mp4"],
    "audios": ["https://example.com/ref-audio.mp3"]
  }
}
```

参考生成会被后端整理成火山方舟 SDK 所需角色：

| 输入素材 | Ark content.type | Ark role |
| --- | --- | --- |
| 参考图 | `image_url` | `reference_image` |
| 参考视频 | `video_url` | `reference_video` |
| 参考音频 | `audio_url` | `reference_audio` |

限制：

- 参考图最多 9 张。
- 参考视频最多 3 个。
- 参考音频最多 3 个。
- 不支持只有文本 + 音频或纯音频输入，至少需要图或视频参与。

## 3.1 文生视频

适用场景：只根据文本提示词生成视频，不使用参考图、参考视频、参考音频、首帧或尾帧。

推荐传法：

```json
{
  "content": "生成一段古风少年在雨中回头的视频",
  "extra": {
    "generation_mode": "text_to_video",
    "resolution": "720p",
    "duration": 5,
    "ratio": "16:9"
  }
}
```

后端最终会发送给 Ark：

```json
[
  { "type": "text", "text": "生成一段古风少年在雨中回头的视频" }
]
```

## 4. 首尾帧模式：只传首帧

适用场景：只指定视频起始画面，结尾由提示词控制。

推荐传法：

```json
{
  "content": "以首帧为起点，人物缓慢转身，镜头轻微推进",
  "extra": {
    "generation_mode": "first_frame",
    "resolution": "720p",
    "first_frame_url": "https://example.com/first.png"
  }
}
```

也可以用 `media_items`：

```json
{
  "extra": {
    "generation_mode": "first_last_frame",
    "media_items": [
      {
        "type": "image_url",
        "image_url": { "url": "https://example.com/first.png" },
        "role": "first_frame"
      }
    ]
  }
}
```

后端最终会发送给 Ark：

```json
[
  { "type": "text", "text": "以首帧为起点..." },
  {
    "type": "image_url",
    "image_url": { "url": "https://example.com/first.png" },
    "role": "first_frame"
  }
]
```

## 5. 首尾帧模式：同时传首帧和尾帧

适用场景：同时指定视频起始画面和结束画面，由模型补中间过渡。

推荐传法：

```json
{
  "content": "从首帧自然过渡到尾帧，中间保持人物身份、服装和场景一致",
  "extra": {
    "generation_mode": "first_last_frame",
    "resolution": "720p",
    "first_frame_url": "https://example.com/first.png",
    "last_frame_url": "https://example.com/last.png"
  }
}
```

也可以用 `media_items`：

```json
{
  "extra": {
    "generation_mode": "first_last_frame",
    "media_items": [
      {
        "type": "image_url",
        "image_url": { "url": "https://example.com/first.png" },
        "role": "first_frame"
      },
      {
        "type": "image_url",
        "image_url": { "url": "https://example.com/last.png" },
        "role": "last_frame"
      }
    ]
  }
}
```

后端最终会发送给 Ark：

```json
[
  { "type": "text", "text": "从首帧自然过渡到尾帧..." },
  {
    "type": "image_url",
    "image_url": { "url": "https://example.com/first.png" },
    "role": "first_frame"
  },
  {
    "type": "image_url",
    "image_url": { "url": "https://example.com/last.png" },
    "role": "last_frame"
  }
]
```

规则：

- 首尾帧模式必须至少传 `first_frame_url` 或等价首帧素材。
- 只传首帧是合法请求。
- 同时传首帧和尾帧时，只允许 1 张首帧图 + 1 张尾帧图，不混入参考图、视频或音频。
- 只传尾帧不合法。

## 6. 兼容字段和 role 别名

首帧 URL 字段兼容：

```text
first_frame_url, first_frame, firstFrameUrl, firstFrame,
first_image_url, firstImageUrl,
start_frame_url, start_frame, startFrameUrl, startFrame,
start_image_url, startImageUrl,
reference_first_frame_url, reference_start_frame_url
```

尾帧 URL 字段兼容：

```text
last_frame_url, last_frame, lastFrameUrl, lastFrame,
last_image_url, lastImageUrl,
end_frame_url, end_frame, endFrameUrl, endFrame,
end_image_url, endImageUrl,
ending_frame_url, endingFrameUrl,
tail_frame_url, tailFrameUrl,
reference_last_frame_url, reference_end_frame_url
```

role 兼容：

| 输入 role | 后端归一 |
| --- | --- |
| `reference`, `image`, `ref_image`, `refImage`, `referenceImage` | `reference_image` |
| `video`, `ref_video`, `refVideo`, `referenceVideo` | `reference_video` |
| `audio`, `ref_audio`, `refAudio`, `referenceAudio` | `reference_audio` |
| `firstFrame`, `start_frame`, `startFrame`, `reference_first_frame`, `referenceFirstFrame`, `reference_start_frame`, `referenceStartFrame` | `first_frame` |
| `lastFrame`, `end_frame`, `endFrame`, `ending_frame`, `endingFrame`, `tail_frame`, `tailFrame`, `reference_last_frame`, `referenceLastFrame`, `reference_end_frame`, `referenceEndFrame` | `last_frame` |

短横线会自动兼容，例如：

```text
reference-video -> reference_video
reference-end-frame -> reference_end_frame -> last_frame
```

## 7. 分镜视频生成接口

接口：

```http
POST /api/v1/projects/{project_id}/chapters/{chapter_id}/storyboards/{storyboard_id}/video-generation
```

请求体：

```json
{
  "ai_model_id": "视频模型 ID",
  "generation_mode": "first_last_frame",
  "resolution": "720p",
  "return_last_frame": false,
  "prompt": "用户补充提示词",
  "first_frame_url": "https://example.com/first.png",
  "last_frame_url": "https://example.com/last.png",
  "extra": {}
}
```

返回：

```json
{
  "task_record_id": "任务 ID",
  "storyboard_id": "分镜 ID",
  "generation_mode": "first_last_frame",
  "resolution": "720p",
  "return_last_frame": false,
  "status": "pending",
  "points_cost": 10,
  "next_poll_seconds": 3
}
```

说明：

- 分镜视频生成的 `generation_mode=first_last_frame` 已支持只传首帧或同时传首尾帧。
- `generation_mode=reference` 会使用上传图、人物、场景、道具等参考图。
- `generation_mode=storyboard` 会使用故事板图像作为主要参考图。

## 8. 注意事项

- 图片、视频、音频 URL 需要是可被火山方舟服务访问的公网地址。
- `resolution` 支持 `480p`、`720p`、`1080p`、`4k`；`4k` 仅 Seedance 2.0 标准模型支持，Seedance 2.0 Fast 不支持 `1080p/4k`。
- Ark Seedance 2.0 当前不支持 `camera_fixed`、`draft`、`draft_task_id`、`frames`、`service_tier` 等参数，传入会被后端拒绝。
- 视频任务为异步任务，前端应根据返回的 `task_record_id` 和 `next_poll_seconds` 轮询任务结果。
