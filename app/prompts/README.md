# 内置提示词

普通项目已采用画布唯一模式。文本、图像、视频节点以 `content.text` 为提示词；画布不会加载此目录的系统模板，也不自动拼接项目风格、章节内容、资产资料卡或其他节点内容。`@{reference_id}` 会按当前节点显式固定的图片输入转换，不能引用未连接内容。

画布生成参数不接受 `system_prompt` 或 `messages`。需要指定写作风格、输出格式等规则时，直接写在节点提示词中。文本节点也不会默认执行章节清洗、资产分析或分镜拆解。

这个目录仍用于以下执行路径，不能因画布不使用就整体删除：

- `system/agent_*.md`：Agent 剧本分析等流程。
- 分镜分析、细化和图像提示词模板：Agent 试播/批量制作仍通过共享分镜服务调用。
- `system/chapter_text_cleaning.md`、人物/场景/道具分析模板：保留的历史任务执行器兼容路径；普通项目已没有新提交入口。
- `constants/asset_image_generation/`：Agent 资产生成通过共享服务使用的固定提示词。

模板读取由 `app/services/prompts.py` 负责，`{{variable}}` 由对应业务服务显式渲染。这里的“业务模板”不一定作为供应商的 system 消息发送；实际消息角色由调用方和供应商适配器决定。供应商适配器的可选 system 消息能力仍被其他执行路径使用。
