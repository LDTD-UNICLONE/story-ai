# 常量提示词

这里存放业务生成时需要拼接的固定提示词。

当前资产图像生成使用：

- `asset_image_generation/character/{generation_mode}.md`
- `asset_image_generation/scene/{generation_mode}.md`
- `asset_image_generation/prop/{generation_mode}.md`

默认生成模式为 `general`。

内置模式：

- `general`：通用生成模式。
- `profile_card`：资料卡模式。

资料卡模式兼容请求别名：`card`、`data_card`、`profile-card`、`资料卡`、`资料卡模式`。
