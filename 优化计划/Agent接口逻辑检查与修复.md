## 核对范围与边界

- 核对入口认证与归属查询、创建配置、启动/暂停/恢复/取消、工作流门禁、分镜视频提交、任务编排、审片和交付；回归覆盖现有 Agent 测试，不表示已经穷举所有业务组合。
- 四步工作流、按分集/分镜生成、模型选择和积分策略沿用现有实现；没有新增推断出的业务能力。
- AOPT-07 已接入共享 Seedance 图片审核；保留 `reference_image` URL 绑定契约，通过用户与凭证范围内的图片记录校验。资产业务确认和图片审核仍分别管理，未增加真人识别或分类逻辑。
- 取消接口仍采用原有任务处理范围：处理活动步骤关联的 pending 任务；不保证撤回已发送的厂商请求。见 `docs/3.0Agent接口文档.md` 第 3.5 节。
- 本轮不迁移数据库、不修改真实业务数据、不启动生成任务或调用付费厂商。已经因旧启动逻辑停在 planning 的任务不会被本次代码更新自动重派，可在确认状态后使用暂停、恢复接口恢复派发。
